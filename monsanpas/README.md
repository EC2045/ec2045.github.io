# モンサンパス公式サイト

東暦世界の架空設定サイト。HTML/CSS/JavaScriptのみで動作します。

日本語・英語は `lang/ja.lang` と `lang/en.lang` のJSON辞書で管理。言語設定は両サイト共通のキーで保存し、未指定の場合はブラウザ言語を使用します。

`setting.json` が今回確定した設定の機械可読記録です。家族の年齢・出生順・親の個人名・企業内役職は未設定。Womiz OSはモンサンパスの所有製品ではありません。

## 動作確認

HTTPサーバー経由で `index.html` を開いてください。IT案内では機器の絞り込み、公式サイトではPC/通信環の画面切り替えができます。実製品やOSのダウンロード機能はありません。
